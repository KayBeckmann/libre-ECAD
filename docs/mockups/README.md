Die Umsetzung übernimmt die Seitennavigation, dunkles Petrol (`#071923`, `#102631`), goldene Hauptaktionen (`#eab75a`), gedämpfte Schrift (`#a8bec1`), umrandete Karten und die Aufteilung von Benutzerverwaltung und Backend-Informationen. Für den Editor existierte kein eigenes Bildmockup; seine Werkzeugleisten verwenden dieselben Farben, die Zeichenfläche bleibt weiß.
